2. WHAT THE SYSTEM DOES
-----------------------
Admin:
- Manage medicines
- Manage suppliers
- Create/delete cashier accounts
- View four reports

Cashier:
- Check medicine stock and prices
- Add items to a cart
- Remove items or clear the cart
- Checkout
- Generate a bill


APPLICATION LAUNCH INSTRUCTIONS

1. Extract the submitted ZIP file.
2. Double-click HamzaMohammad_pims.exe to install the application.
3. The Health First Pharmacy login screen will appear.


3. SETTING UP MYSQL
-------------------
1. Install MySQL.
2. Open MySQL Workbench or another MySQL client.
3. Run database.sql.
4. This creates the healthfirst_pims database and sample records.


4. SETTING UP JAVA
------------------
1. Open the /src folder in a Java IDE such as NetBeans, IntelliJ IDEA or Eclipse.
2. Add MySQL Connector/J to the project libraries.
3. Open DBConnection.java.
4. Check the MySQL username and password.
5. Run LoginPage
